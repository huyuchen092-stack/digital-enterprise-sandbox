## 预算表结构

`1234568.xlsx` 包含：

- `第一年`、`第二年`、`第三年`、`第四年`：年度季度预算表。
- `产能表`：按产线、基础产能、初级工、高级工、班次计算产能和生产费用。
- `材料表`：按产品、特性、原料需求、原料价格和提前季计算材料费用。
- `激励表`：按员工当前效率、目标效率和单位价格计算激励费用。

年度表的核心不是结果展示，而是滚动预算模型：每个季度都从期初现金开始，扣除还款、利息、管理、人力、生产、市场、违约等支出，加上贷款、回款、贴现、出售等现金流入，得到季末现金。

## 核心公式

产能表明确使用：

```text
单线产能 = INT(基础产能 × (1 + 初级工效率和 / 4 + 高级工效率和) × 班次)
生产费用 = 线型计件工资 × 单线产能
```

年度表使用的季末现金结构：

```text
季末现金 =
期初现金
- 短款/短息
- 长款/长息
- 管理费
+ 应收回款
+ 贴现
- 贴现利息
- 碳中和/紧采
+ 出售
- 人力预算
- 维护
- 生产预算
- 市场预算
- 违约
```

第一年贷款额度结构：

```text
贷款额度 = 股本 × 贷款倍数 + 本季短款 + 本季长款 - 本季新增贷款
```

后续年份会从上一年资产负债表继续滚动：上一年期末现金、税、长贷、短贷、权益、利润留存都会影响下一年可用额度。

## 推方案顺序

正确顺序应是：

1. 先读规则参数：股本、贷款倍数、利率、管理费、贴现利率、产线价格/周期/转产、产品研发、材料价格/提前季。
2. 再读市场订单：年份、季度、产品、市场、价格、数量、交货期、账期。
3. 计算产品材料成本和单位毛利，不用销售额直接当利润。
4. 按组均容量和交货季反推需要多少可交付产能。
5. 试一个产线组合，把产线、研发、材料、人力、市场、广告、贷款、贴现放进季度预算表。
6. 检查每个季度季末现金是否为正，并且是否能覆盖下一季刚性支出。
7. 跑不通时先定位现金断点：是购线过多、广告过高、原料提前采购、研发过早、回款账期太长，还是贷款额度不足。
8. 跑通后再比较净利润和年末权益，不能只比较产能或广告排名。
9. 最后才输出候选开局方案，让用户在“现金风险、广告目标、净利润、后续产能节奏”之间选择。

## 当前系统需要纠正的点

当前系统已经能读取部分规则/市场并做候选比较，但还不够像这套预算表：

- 不能只用 `产线表产量 × 线数` 当产能，必须接入初级工、高级工、班次和激励。
- 不能只算“开局投入后现金缓冲”，必须逐季滚动到交货前和回款前。
- 不能只按贷款总额度判断可买线数，还要看贷款发生季度、利息、还款方式和上一年权益。
- 广告额不能孤立估算，必须放在广告投放时点的可用现金里校验。
- 净利润必须经过收入、材料、生产费、人力、管理、广告、财务费用、税一起推，不能只用毛利减几个大项。

## 结论

后续方案推演模块应升级为“预算引擎”：

```text
规则/市场证据
→ 产能/材料/人力/研发/贷款参数表
→ 逐季预算表
→ 现金断点检查
→ 候选方案比较
→ 推荐可选开局
```

不经过预算表跑通的方案，只能标记为“粗估”，不能作为最终开局建议。
