# 高职省赛案例方案思路沉淀

这份知识来自 `高职-省赛规则.docx`、`高职-省赛详单.xls`、用户预算表流程和用户对广告/拆线逻辑的纠正。它不是固定模板，而是后续遇到类似高职赛题时必须复用的判断链。

## 核心定性

本题属于：

```text
7自动跑P2现金流 + 后续补智能 + 自动线前期不转产 + Y2按广告排名/订单预期拆自动换智能
```

不能按保守 4 自动开局，也不能开局硬智能。Y1 的核心是用自动线速度和 P2 毛利打出第一年现金流；Y2 起用智能线去承接 P3/P4，自动线继续 P2 低广告获取订单或等待拆线。

## 开局逻辑

用户方案：

- Y1：7 条自动线跑 P2。
- 自动线一般不转产。
- 后续补智能线。
- Y2 根据广告排名、可得订单和现金流，判断能不能拆自动换智能。

关键原因：

1. P2 在 Y1 有较高毛利，紧急采购后仍有利润。
2. 现金满激励、紧急采购后仍可剩约 22 万，说明 7 自动不是拍脑袋，而是预算能压线跑通。
3. 25 组市场中，不是所有队都会紧急采购 P2；会紧急采购做 P2 的队伍，产能通常和本方案接近，因此广告不一定特别高。
4. 自动线转产周期 1 季。若 Y2 转 P3/P4 会损失生产季，所以自动线前期不转产，让智能线承担 P3/P4 切换。

## 广告与市场判断

广告不是固定金额，而是由目标市场、产能和顺位反推。

### 市场大小判断

先按市场总量和队伍数判断市场：

- 大市场：总量大，多数队伍可拿单，低广告可承接。
- 中市场：需要一定顺位，广告适中。
- 小市场：只够少数队伍，必须高广告。

用户口径：

```text
用自己的极限产能 / 产品总量反推需要的广告顺位。
```

例：

```text
1.2 P1 总量 10000，P2 总量 5000。
如果本季度产能 400，要承接 P2，则大约需要进入前 5000 / 400 ≈ 前12名。
P1 是在取得 P2 顺位时顺带获取到。
```

### P1/P2 转换与利差

如果要从 P1 转 P2：

1. 先算获取到 P2 需要的广告顺位。
2. 再看 1.3 是否还有 P2。
3. 比较 P1 与 P2 的利差。
4. 如果 1.2 为抢 P2 需要的广告已经高过 P1/P2 利差，则 P2 实际收益接近 P1，可能考虑 1.3 再用低广告拿单。

核心原则：

```text
广告超过产品利差时，高毛利产品可能被广告承接平，不应盲目追。
```

### 本题 Y1 市场口径

- 1.2 先看 M1 能不能嫖到订单。
- 若 M1 嫖不到，则主承接 M2。
- 因为做 P2 的队伍要么产能不大，要么和本方案类似也不愿高广告，所以 7 自动方案的广告压力不一定高。
- 1.2 可通过对手竞单详情观察：多少队伍卖两批 P1，多少队伍卖 P2，从而判断 P2 竞争强度。

## Y2 运营逻辑

Y2 自动线一般不转产。

原因：

- 自动线转产损失 1 季。
- P2 可以放到全是 P2 的市场低广告/低广告获取订单。
- M3 市场只有 P3/P4，竞争相对更小，更适合智能线灵活转产去承接。

用户预算口径：

- 第一年度赚钱后可上 5 条智能线。
- 因此 Y2 只需要再上 4 条智能线，即可快速形成智能主力。
- 智能线用于 P3/P4，自动线继续 P2。

## 拆线时点

拆线不是等全局订单完全确定后才做，而是在广告排名明朗后做极限预算。

用户操作口径：

1. 投完广告。
2. 看到广告排名。
3. 交一交订单前，把应收贴现出来。
4. 根据广告排名大致推算自己能得到的订单。
5. 用可得订单和现金流反推极限能上多少智能线。
6. 如果能上到 11 条，而当前有 4 条空位，则需要拆 7 条自动线来上智能。

因此拆线判断节点是：

```text
投完广告、广告排名确定后、交一交前贴现并重跑预算。
```

不是简单的“年初固定拆”或“订单完全确定后才拆”。

## 拆线计算

拆线要算：

```text
拆线净收益 =
(新智能线单季贡献 - 旧自动线单季贡献) × 剩余可生产季数
- 停产/安装损失
- (智能线价格 - 自动线残值)
```

本题如果 P4 订单可预期且智能线能承接，拆自动换智能通常值得算，因为：

- 自动线继续做 P2 单线贡献较低。
- 智能线做 P3/P4 单线贡献更高。
- 智能线转产 0，适合 M3 的 P3/P4 市场。

但是否一次拆 7 条，要由广告排名、可得订单和贴现后现金决定。

## 后续推本题必须遵守

1. 不要再推荐 4 自动保守开局作为主方案，主线应以 7 自动跑 P2 为候选核心。
2. 不要让自动线轻易转产，Y2 自动线默认继续 P2。
3. 智能线承担 P3/P4，尤其 M3 这种只有 P3/P4 的市场。
4. 广告目标要用产能除以产品总量反推顺位，再结合市场大小和对手竞单详情估广告额。
5. 广告额必须和产品利差比较，广告超过利差时要重新判断是否值得抢。
6. 拆线必须放在广告排名确定后、交货贴现前后重跑预算，而不是赛前固定写死。
7. 输出方案必须给出：7 自动 P2 现金流、Y2 补智能数量、广告顺位、拆线触发条件和拆线后现金流。
