# 预算表流程学习：方案转预算动作

本文件来自用户预算表 `10.4大喜.xlsx` 与补充文档 `新建 DOCX 文档 (2).docx`。它不是某个案例模板，而是智能体把自然语言方案转成预算输入时必须遵守的流程。

## 1. 方案拆解顺序

用户一句“7自动跑 P2，后续补智能”必须拆成结构化动作：

- 第几季买线、哪类线、几条。
- 第几季员工到岗，低级工/高级工各几人。
- 第几季下材料，按原料送货期倒推。
- 第几季材料到货并付款。
- 第几季生产、生产什么产品/特性、用哪些线。
- 第几季入库、可交哪个交期订单。
- 第几季投广告、目标市场/产品/特性/顺位。
- 第几季交货、回款或贴现。
- 第几季补线、拆线、转产、激励。

如果用户没有明说，不能直接拍线数，必须先按规则参数推默认动作。

## 2. 建线默认规则

产线是否提前建，取决于“建成当季是否能生产”，而不是只看安装周期。

```text
可生产季 = max(产线建成季, 产品资质完成季, 材料到货季, 员工到岗季, 市场/ISO满足季)
```

默认判断：

- 自动线建造 1 季、生产 1 季时，如果 1.2 能生产，则倾向 1.1 上线。
- 如果关键材料送货期导致 1.2 不能生产，或者紧急采购也赶不上，则可延期到 1.2 上线，避免 1.1 建成后空转。
- 传统线即使安装 0 季，也不能默认 1.1 生产；若材料送货期为 1，1.1 下料通常 1.2 到货付款后才能生产。
- 若 1.2 现金足够紧急采购并生产，提前建线有价值；若不够紧采，提前建成没有意义。

## 3. 材料采购与预算填表口径

材料必须按生产季倒推：

```text
下单季 = 生产季 - 原料送货期
付款季 = 到货季
```

预算表中常见口径：

- 1.1 下材料，1.2 表中体现材料费用。
- 1.2 下材料，1.3 表中体现材料费用。
- 材料费用不是生产季随便填，必须与到货付款季对应。
- 如果产品需要 R3 且 R3 送货期为 2 季，1.3 生产需要 1.1 下单；若紧急采购规则仍赶不上，则不得安排该批生产。

## 4. 广告现金口径

广告现金不是账面现金，而是扣完当季必要动作后的可动用现金。

```text
广告前可用现金 =
期初现金
+ 本季可确定融资
+ 本季可确定回款/预算贴现
- 市场/ISO/产品/特性研发
- 建线/拆线/转产
- 材料到货付款
- 生产费/计件
- 工资
- 激励
- 管理费
- 到期短贷本息
- 税款
- 必要安全垫
```

第一年 1.2 广告季通常没有上一批入库，不能把交货贴现算进 1.2 广告现金。

除 1.2 外，如果广告季前已有“一交”产品可交货，预算时可以先算交货贴现，再得出极限广告额。但实战不是默认把所有应收都贴现，而是用贴现调预算：

- 先看广告、材料、生产、补线、激励缺多少钱。
- 贴现只贴到预算可过、动作可做的程度。
- 若市场竞争激烈，贴息再高也可能必须贴；没有订单会拖慢发育。
- 若贴现只是为了过度补线导致后续广告现金断裂，则应减少补线。

## 5. 广告经验与市场大小

广告额不能直接拍，要先算顺位。

```text
目标顺位 ≈ 目标产品市场总量 / 自己可交产能
```

市场大小判定：

- 大市场：市场总量 / 自己极限产能 远大于参赛组数。重点拉产能，广告不需要过度挤压现金。
- 中市场：市场总量 / 自己极限产能 接近主要竞争队数量。需要下产能留广告，广告与产能都重要。
- 小市场：市场总量只能满足少数队伍。优先广告顺位，产能过多但广告不足会拿不到订单。

若 10 条线方案广告 60 万、8 条线方案广告 100 万，小市场中 8 条线可能比 10 条线更稳，因为 10 条线可能卡在拿不到订单的位置。大市场中则更偏向极限产能。

广告是否值得，还要比较产品利差：

```text
产品利差 = 不同产品/市场/交期间单件利润差 × 可交数量
```

如果为抢高利润产品多投的广告已经超过利差，应考虑换市场、降低广告、下季再投，或承接低竞争订单。

## 6. 激励与补线默认优先级

补线通常优先于初级工激励。

原因：初级工效率进入产能公式时通常要除以 4，新增产能较少；一条新线带来的产能常大于初级工激励增量。

默认规则：

- 高级工对产能影响大，优先测试高级工满激励。
- 初级工激励必须做边际收益：新增产能 × 单件现金毛利，能否覆盖激励、材料、计件和现金压力。
- 若初级工激励会挤掉广告、材料或补线，优先保证广告顺位和补线。
- 若第一年不满高级工激励可以多上一条线，并且市场广告能支撑，则可先上线；1.3 交货/贴现后再把高级工激励满，让 1.4 入库产能提升。
- 激励必须等员工到岗后才发生，不能在员工未到岗时提前激励。

## 7. 补线与广告现金关系

广告现金高于目标顺位所需金额时，不应盲目多打广告，应检查是否可以：

- 补线。
- 备关键材料。
- 满高级工激励。
- 研发高利润产品、市场、ISO。
- 留下季度税款/还款/材料安全垫。

若补线后广告现金为负，说明补线数量过多，要减少补线或降低当季生产/激励。

## 8. 拆线触发规则

拆线不是赛前固定动作，而是动态动作。

实战触发：

- 快满线或已满线时，如果手里还有现金、广告金额够、后续目标线型明显更优，可以提前拆不需要的线。
- 投完广告看到排名后，根据能获取的订单和当年可承接产能决定拆几条。
- 当年拆线会损失当年产能，必须保证当年利润仍为正。
- 若拆线能赚但会挤压下一季广告现金，先看是否有应收可贴现；可贴现则可拆，不可贴现则等回款或少拆。

拆线净收益：

```text
拆线净收益 =
(新线单季贡献 - 旧线单季贡献) × 剩余可生产季数
- 当年停产损失
- 新线价格
+ 旧线残值
- 额外融资/贴现成本
```

## 9. 最高有效产能

最高有效产能不是生产线上限，也不是单纯 16 条线。

它是高利润产品出现前或出现时，满足以下条件的最大可交产能：

- 产线配比是当前规则下的最优或接近最优。
- 员工数量和激励能支撑。
- 材料到货和现金能支撑。
- 产品资质/市场/ISO满足。
- 广告顺位能把这部分产能转化为订单。

如果自动线和智能线产能差距小，且自动线建造更快、转产可控，可优先补自动。若自动线有转产周期，而市场产品变化灵活或高利润产品很早出现，即使产能差距小，也要优先智能线或提前准备拆线。

## 10. 输出候选方案的硬字段

每套候选方案必须至少输出：

- 第一年利润。
- 第一年广告额与可支撑顺位。
- 第几年第几季度达到最高有效产能。
- 广告前可用现金最低点。
- 材料付款高峰季。
- 是否需要贴现/短贷。
- 注意事项：资质、材料、激励、拆线、税款、订单覆盖期。

不能只输出“推荐方案”。必须给用户可以选择的对比项。
