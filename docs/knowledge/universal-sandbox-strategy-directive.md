# 数智化企业经营沙盘通用推演指令

这份指令用于面对不同省赛、不同规则、不同市场结构时统一推方案。它不是某一个案例模板，而是推演流程。后续任何赛题都必须先走这套流程，再输出方案。

## 0. 总原则

方案不是拍线数、拍广告、拍产品，而是：

```text
读规则 → 分市场 → 算产品利润 → 算产线真实产能 → 倒推材料 → 枚举候选 → 跑现金流 → 判断广告顺位 → 动态补线/拆线 → 四年权益最大化
```

任何没有跑过季度现金流、没有校验材料到货、没有说明广告顺位的方案，都不能称为跑通方案。

最高目标不是“活下来”或“方案能过”，而是**在规则允许范围内争第一、做市场霸主**：

```text
现金流安全是底线，不是目标上限。
产能、广告、融资、产品切换、拆线，都要服务于抢关键市场、压制对手、形成订单垄断能力。
```

推演时必须默认站在争一视角：

- 能用现金流滚动支撑的激进产能，要优先测试。
- 能通过广告顺位锁定高毛利市场的方案，要优先评估。
- 能让对手拿不到关键订单、只能转向低毛利剩余市场的策略，要作为高优先级方案。
- 若保守方案权益稳定但无法争一，只能作为风险备选，不能作为默认推荐。
- 输出推荐时必须回答：这套方案如何扩大领先、如何抢市场、如何压制对手，而不只是“现金流能过”。

若比赛规则给出最终评分公式，必须把评分公式作为最高优化目标。不能只优化所有者权益。

例如江苏省赛通知中的经营发展指数口径：

```text
企业经营发展指数 =
(所有者权益 + 数智化建设费用 × 10 - 预算控制扣分)
× 第四年商誉
× (1 + 第四年碳中和率 + 第三年碳中和率)
```

遇到这类评分规则时，四年战略必须同时优化：

- 所有者权益。
- 数智化建设投入的得分杠杆。
- 商誉维护。
- 第三年、第四年碳中和率。
- 预算控制扣分。

不能为了短期权益完全不做数智化、社会责任或碳中和；也不能盲目做数智化，必须比较“数智化费用 × 10 的得分收益”和现金流/利润机会成本。

新增硬原则：**先测产能上限，再用现金流控制产量**。

```text
可建线数上限 → 员工到岗/激励后真实产能 → 可接订单上限
→ 材料/工资/广告现金约束下的实际生产量 → 季度现金流
```

不能因为满产现金流暂时过不去，就直接把产线数保守砍掉。若产线建成后未来季度能创造订单和贷款额度，且当前建线现金能过，则应保留“先建线、分批生产/减产”的候选方案。

新增硬原则：**生产能力必须由“产线参数 × 人员效率 × 材料到货 × 现金流”共同决定**。

```text
某线某产品某季度能否生产 =
产线已建成
× 产品/市场/ISO资质已满足
× 材料按送货期已到货或能紧急采购
× 对应工人已到岗
× 激励/工资/计件/材料/广告后现金不为负
```

产能不是平均估算，也不是只看基础产量。每次制定方案时，都必须先把规则参数组合成“可生产矩阵”：

```text
产线类型 × 产品 × 季度 × 工人效率 × 材料到货 × 现金流
```

只有矩阵中同时满足的产能，才可以进入广告顺位和订单承接判断。

## 1. 规则读取清单

拿到规则后，必须先结构化读取：

- 初始资金、贷款倍数、短贷/长贷/直接融资利率和期限。
- 管理费、税率、违约金、咨询费、碳中和费用。
- 市场开拓费用和周期。
- ISO/认证费用和周期。
- 产品资质费用和周期。
- 产品 BOM、产品成本、开产费。
- 原料价格、送货周期、账期、紧急采购倍数。
- 产线价格、安装周期、生产周期、基础产量、转产周期、转产费、残值、维护费。
- 工人配置、工资、计件、招聘数量、初始效率。
- 激励方式、效率提升比例、班次加成、效率损失。
- 数字化费用、周期、对产能/广告/下料/招聘/风控的影响。
- 订单详单：年份、季度、市场、产品、特性、价格、数量、交期、账期、认证要求。

读取不清楚的参数必须标注“未知”，不能用经验值硬填。

## 2. 题型分类

每道题先分类，不先推荐产线。

### 自动速度套利题

特征：

- 自动线便宜、安装快、生产周期短。
- 前期产品毛利足够。
- 材料能及时到货或现金够紧采。
- 自动线转产损失可控，或前期不用转产。

策略：

- 前期优先测试自动线极限开局。若线价现金可过、建成当季能生产，则产线尽量早上；实际生产量由材料、广告和现金流决定。
- 不允许用“满产现金流不过”直接否定多自动线方案，必须先测试“多线低产/分批产/用早交订单托现金流”。
- 自动线速度套利题的关键不是少线保守，而是用早建成的产能抢广告顺位、抢订单、放大 Y1 权益和 Y2 贷款额度。
- 后续根据高利润产品和转产损失决定补智能或拆自动。

### 智能长期高利润题

特征：

- 智能线满激励产能明显高于自动线。
- 智能线转产 0，自动线转产损失大。
- P3/P4/P5 高利润产品出现早或剩余季数多。

策略：

- 开局或中期优先补智能。
- 用高利润产品覆盖智能线差价。

### 低价传统线规模化题

特征：

- 传统线虽然生产周期长、转产慢，但购买价远低于自动/智能线。
- 传统线在 12 时制或满激励后单线产能很高，能快速形成总产能优势。
- 前中期市场容量大，广告顺位获取后需要足够产能承接订单，否则高广告会浪费。
- 后期高利润产品出现较晚，前期有足够时间用传统线滚动现金流和权益。
- 可通过拆线重装、分批替换或保留部分智能线来解决后期转产灵活性。

策略：

- 不允许因为“传统线生产周期 2 季”直接排除传统线。
- 必须比较“传统线低价大产能带来的订单承接能力和权益滚动”与“智能线灵活高毛利”的差异。
- 若传统线能显著提高广告覆盖率，使高广告转化为实际订单承接能力，应把传统线作为争一候选。
- 后期高利润产品来临前，提前配置少量智能线或提前研发/开市场/开 ISO，为转型准备。
- 传统线转产慢时，必须测算“拆线重装”是否优于转产停产。

### 费用膨胀现金流题

特征：

- 初始资金和贷款额度看似大。
- 市场、ISO、资质、材料、线价、工资、税额都同步很贵。

策略：

- 先找现金峰值，再排线。
- 年末必须测税后现金，而不只看季末现金为正。

### 材料卡节奏题

特征：

- 关键材料所有产品都要。
- 关键材料送货周期长。
- 紧采成本高或现金不足。
- 产线虽然已经建成，但材料未到货，导致产线只能空转，最早生产季晚于建成季。

策略：

- 先排材料采购，再排产线。
- 产线建成当季没有材料且不能紧采，则提前建线无意义。
- 任何产线都必须同时给出两个时间：

```text
建成季 = 购买季 + 安装周期
可生产季 = max(建成季, 资质完成季, 材料到货季, 员工到岗季)
```

若 `可生产季 > 建成季`，必须说明产线空转原因。不能把“安装周期 0”误写成“当季一定能生产”。

### 拆线替换题

特征：

- 前期自动线赚钱。
- 后期智能线承接高利润产品明显更优。
- 自动线不转产或转产损失大。

策略：

- Y2/Y3 根据广告排名、可得订单、贴现现金动态拆线。
- 拆线不是固定动作，而是预算动作。

### 题型优先级与最优方案评判

若一道题同时满足多种题型特征，不按模板优先，而按以下目标排序：

```text
第一优先：第一年利润和第一年权益滚动
第二优先：达到最高有效产能的时间
第三优先：高利润产品出现前是否已经准备好产能、资质、市场和材料
第四优先：广告时点现金是否足以达到目标顺位
```

这里的“最高有效产能”不是简单的生产线上限，而是：

```text
最高有效产能 =
在目标高利润产品出现时，
满足产线建成、员工到岗、激励可承受、材料可到货、订单可销售、现金流不断裂的最大可交产能。
```

通常优先选择更早达到最高有效产能的方案，但必须结合产品利润变化。如果某方案更早满产但只能生产低利润产品，而另一方案稍晚但能在高利润产品出现前完成转型，则必须比较两者四年权益和高利润季订单承接能力。

最优解可以不止一种。正式输出时不强行只给一个答案，必须给用户可选择的候选，并按统一指标对比：

| 方案 | 第一年利润 | 第一年广告额/可打广告 | 达到最高有效产能时间 | 注意事项 |
|---|---:|---:|---|---|

其中“第一年广告额/可打广告”必须说明对应广告季和目标市场顺位，让用户判断是否稳定获取订单，并推断第二年一季度广告现金是否充足。

## 3. 市场分析方法

市场不能按平均获取订单，必须按竞争性口径分析。

### 市场大小

按产品、市场、季度分别判断：

```text
大市场：总量大，多数队伍可拿单，低广告获取订单可行。
中市场：需要一定顺位，广告适中。
小市场：只够少数队伍，必须高广告，否则拿不到单。
```

争一口径下的市场判断：

- 大市场不是“随便获取部分订单”，而是判断能否低广告销售满产，并省钱去抢下一市场。
- 中市场是最常见的优势战场，要用产能和广告顺位把对手挤到低价/低毛利订单。
- 小市场不是默认回避，若其中是高毛利战略产品，必须测算高广告垄断后是否仍然净赚。
- 市场霸主不是平均分散获取订单，而是在关键产品/关键市场形成可交产能和广告顺位优势。

### 顺位反推

用自己的可交产能反推广告顺位：

```text
需要顺位 ≈ 目标产品市场总量 / 自己可交产能
```

例：

```text
P2 市场总量 5000，自己产能 400
则要获取到 P2，广告顺位大约要前 12。
```

### 产品利差与广告

广告不是越高越好，必须和产品利差比较：

```text
若为抢高利润产品多花的广告 > 高利润产品相对低利润产品的利差，
则高利润产品实际优势被广告消耗，需要考虑低广告销售低利润产品或下一季再投。
```

### 对手竞单信息

如果比赛系统能看到竞单详情，必须利用：

- 多少队伍做 P1。
- 多少队伍做 P2。
- 多少队伍能卖两批。
- 多少队伍紧采。
- 对手产能是否和我接近。

这决定广告经验额，而不是只看市场总量。

## 4. 产品选择方法

产品选择按三层判断：

1. 单件毛利：售价 - 产品成本 - 特性升级成本 - 生产计件。
2. 实际毛利：单件毛利 - 紧采额外成本 - 广告分摊。
3. 现金毛利：考虑账期、贴现息、材料付款季后的现金贡献。

早期可以选择不是最高毛利的产品，只要它能跑出现金流和贷款额度。

产品选择必须区分“利润产品”和“现金托底产品”：

- 利润产品：单位毛利高、适合主投广告和主排产。
- 现金托底产品：可能单位毛利较低，但交期早、账期短、可贴现，能支撑下一批高利润生产。
- 若高利润产品只能晚交、现金断在中途，应先用早交产品托现金，再切高利润产品。
- 不能因为现金托底产品毛利低，就否定它在开局方案中的战略价值。

## 5. 产线选择方法

不能只看基础产量，必须算真实产能：

```text
真实产能 = 基础产量 × (1 + 初级工效率和 / 4 + 高级工效率和) × 班次加成
```

产能公式必须从规则读取，不允许固定套用。若规则给出不同公式，必须以规则公式为准；若未给公式，才使用上面的通用口径并标注“按通用公式估算”。

计算产能时必须拆成三层：

```text
理论产能：产线建成 + 员工满效率 + 满班次，不考虑材料和现金。
可生产产能：理论产能中，资质/材料/员工到岗满足的部分。
实际排产：可生产产能中，现金流、广告订单、材料采购资金允许生产的部分。
```

制定方案时先用理论产能判断“这套线型有没有争一上限”，再用可生产产能判断“这个季度能不能交货”，最后用实际排产跑现金流。不能把三者混在一起。

比较产线时必须同时看：

- 线价/产能。
- 安装周期。
- 生产周期。
- 转产周期和转产费。
- 工人需求和工资。
- 激励成本。
- 维护费。
- 残值。
- 高利润产品剩余季数。

传统线特殊检查：

```text
传统线有效价值 =
低线价节省现金
+ 高产能带来的订单承接能力
+ Y1/Y2 权益滚动和贷款额度放大
- 生产周期变长导致的回款延迟
- 转产周期/拆线重装损失
- 后期高利润产品切换机会成本
```

如果市场容量大、广告需要产能覆盖、且高利润产品爆发较晚，传统线可能比智能线更适合前期争一。
不能仅因传统线“慢”就排除，也不能仅因传统线“便宜”就盲目满上传统线。

开局产线判断：

```text
建成当季能生产 → 可以提前上线。
建成当季没材料且不能紧采 → 提前上线会空转，应延后。
```

更严格的预算口径：

```text
买线预算只证明“产线能建”；
材料到货、资质完成、员工到岗和激励现金共同证明“产线能生产”。
```

因此做方案必须分三张表：

- 建线表：购买季、安装周期、建成季、维护开始年份。
- 材料表：产品/BOM、下单季、到货季、付款季、是否紧急采购。
- 排产表：生产季、入库季、交货批次、所需材料是否已到货。

没有材料表，不允许宣称某条线某季度能生产。

产线数量判断必须分两层：

```text
建线可行性：买线、招聘、基础费用后现金是否能过。
满产可行性：材料、工资、激励、广告、特性升级后现金是否能过。
```

如果“建线可行但满产不可行”，正确动作通常是：

- 保留产线，降低当季生产量。
- 先生产早交/短账期产品回现金。
- 高级工优先激励，初级工视增产毛利决定。
- 延后部分材料采购或特性升级。
- 用贴现/短贷滚动支撑第二批生产。

不能把“满产不可行”误判为“产线不可建”。

## 6. 材料采购方法

材料必须倒推，不允许生产时才想材料：

```text
下单季 = 生产季 - 送货周期
付款季 = 到货季
```

如果原料提前季为 1：

```text
1.1 下单 → 1.2 到货付款 → 最早 1.2 开产
```

这时即使传统线/手工线安装周期为 0，也不能安排 1.1 生产，除非规则明确给了期初库存或允许并支付紧急采购。

若材料来不及：

- 紧急采购。
- 减产。
- 换产品。
- 延后生产。

紧采判断：

```text
紧采后单件毛利 > 0
且紧采付款季现金流不断
才允许紧采。
```

## 7. 激励与班次方法

激励不是固定第一时间打满。

判断：

- 员工未到岗，不激励。
- 产线不能生产，不激励。
- 材料不到，不激励。
- 高级工通常优先激励，因为直接乘产能。
- 初级工影响除以 4，要算增产毛利是否覆盖激励。
- 现金紧时，可以先上线/买材料，后续再激励。

高级工满激励必须作为默认候选而不是事后补充：

- 若高级工已到岗、产线可生产、存在正毛利订单，高级工激励到 100%通常优先测算。
- 初级工不激励或少激励应作为现金流优化项，因为初级效率进入公式要除以 4。
- 每套候选方案必须列出“高级满激励/初级不激励”和“全员满激励”两个产能口径，除非规则明确激励无效或现金绝对不足。

激励决策必须用边际产能计算，而不是一句“高级优先”：

```text
某类工人激励后的新增产能 =
基础产量 × 人数 × 效率提升比例 × 班次加成 × 工人权重

高级工权重 = 1
初级工权重 = 1/4

新增毛利 =
新增产能 × 目标产品单件现金毛利

激励净收益 =
新增毛利 - 激励费用 - 新增计件工资 - 新增材料现金成本 - 可能增加的贴现/贷款利息
```

决策规则：

- 高级工：只要员工到岗、材料到货、产线可生产，且新增毛利能覆盖激励和现金压力，就优先测满 100%。
- 初级工：必须逐档测算，不默认满激励。因为初级工效率要除以 4，常常需要比较“多出的几件产能”是否真的值得。
- 现金流紧张时，激励不是看利润表，而是看激励当季现金是否会挤掉材料、广告或贷款安全垫。
- 若激励后新增产能无法获得订单，或广告顺位不足以销售新增产能，则不应激励或只低档激励。
- 若高利润产品即将出现，低利润季度的初级激励要比较“现在激励增产收益”与“把现金留给下季补线/广告/材料”的机会成本。
- 激励必须与市场大小联动：
  - 大市场：若新增产能基本都能销售，产能优先级更高，但仍要比较初级工激励费用是否不如多上一条线及其配套材料/生产费。
  - 中市场：先算目标顺位和广告额，再决定初级工激励。若广告不够，初级工激励可能让产能变成卖不出去的库存。
  - 小市场：广告顺位优先于初级工激励。若抢不到订单，初级工新增产能没有意义。
- 若初级工激励占用的现金足够多上一条线，并且这条线的材料、生产费、工资能配套，则即使当季度高级工未满激励、短期产能少一点，也要优先测试“先上线、下季再激励高级工”的方案。原因是下一季度有产能入库和订单贴现后，可以再把高级工补到 100%，形成更高持续产能。

每个候选方案至少输出三档激励口径：

```text
A档：不激励/最低激励，保现金。
B档：高级工满激励，初级工不激励或低激励。
C档：高级工满激励 + 初级工按边际净收益激励到最优档。
```

不能只输出“全员满激励”或“完全不激励”。

## 8. 现金流推演

每个候选必须逐季度跑：

```text
期初现金
+ 收款/贴现
+ 新增贷款
- 还款本息
- 市场/ISO/资质
- 购线/维护/转产/拆线
- 材料付款
- 工资/计件/激励/培训
- 管理费
- 广告
- 税
= 季末现金
```

现金流检查：

- 每季度末现金 >= 0。
- 交货前现金 > 0。
- 年末现金 >= 所得税。
- 税后现金能支撑下一季度广告、还款、材料、工资。

广告时点现金必须是扣除刚性支出后的现金，不是贷款后的账面现金。

### 广告时点现金口径

广告可用现金不是“账上有多少钱”，而是当季投广告前、完成必要动作后的可动用余额：

```text
广告时点可用现金 =
期初现金
+ 当季广告前可借短贷/长贷
+ 已入库并可交货订单的贴现金额
- 前序已发生费用
- 当季必须发生的市场/ISO/资质/产品/特性费用
- 当季建线/补线/拆线/转产费用
- 当季生产所需材料到货付款
- 当季生产费/计件工资
- 当季应付工人工资
- 当季计划激励费
- 到期贷款本息
- 税款与必要现金安全垫
```

第一年 1.2 广告季通常没有上一批产品入库，因此不能把交货贴现算入 1.2 广告现金。

除 1.2 之外，若广告季之前已有“一交”或其他可交货订单入库，则极限广告额必须先把交货后可贴现现金算入。也就是说：

```text
有入库可交订单：先交货/贴现 → 再计算广告极限
无入库可交订单：只能用期初现金 + 融资 - 必要支出计算广告极限
```

广告极限额只代表最多能打多少，不代表应该全打。若手上现金低于达到目标顺位所需广告，则最大广告额就是手上可用现金；若手上现金高于目标顺位所需广告，不能把多余现金盲目打广告，应该优先检查能否补线、备材料、激励高级工或为下季高利润产品做准备。

若补线导致广告时点现金为负，说明补线数量过多，需要减少补线或调整生产/激励；不能让产线方案把广告现金挤成负数。

### 订单合并申报与广告现金压力

当第三年、第四年出现“订单数量少但单量大”的市场时，不能只按单个交货批次抢订单，必须考虑把多个交货批次合并到一个订单/一次申报中获取市场份额。

合并申报的核心不是“广告能不能打出去”，而是：

```text
广告投出后 → 所有合并批次交货前 → 每个季度现金流都必须为正
```

检查规则：

- 合并 1交 + 2交：重点检查第二季度交货前的现金流，至少保证第一季度现金流为正，并保证第二季度交货前现金不为负。
- 合并 1交 + 2交 + 3交：必须保证前两个季度现金流为正，第三季度交货前现金不为负。
- 合并到 4交或全年订单一起申报：必须保证前三个季度现金流为正，第四季度交货前现金不为负。

因此，大单广告额要做“交货前现金流压力测试”：

```text
可承受广告额 =
广告时点可用现金
- 合并订单覆盖期内的材料付款
- 合并订单覆盖期内的生产费/计件/工资/激励
- 覆盖期内的维护/转产/补线/还款/税费
- 必要现金安全垫
+ 覆盖期内可确定的交货贴现/回款
```

若合并订单的广告打高后，会导致合并覆盖期内任一季度现金为负，则该广告额不可用；必须降低广告、拆分订单、减少产量、贴现、融资或调整补线/激励节奏。

大单合并申报时，广告顺位和现金流必须同时输出：

- 合并批次：例如 1+2交、1+2+3交、全年合并。
- 合并订单总量与目标顺位。
- 广告时点可用现金。
- 合并覆盖期内各季度最低现金点。
- 是否需要贴现或短贷支撑。

现金流推演要同时输出两种口径：

- 极限产能口径：现有产线和工人激励后最多能生产多少，用于判断广告顺位和市场上限。
- 实际排产口径：在材料、工资、广告、贴现、回款约束下本季度实际生产多少，用于判断现金是否断裂。

不能把实际排产量误当成产能，也不能把极限产能直接当成现金流可承受产量。

## 9. 广告策略

广告推演步骤：

1. 确定目标产品和市场。
2. 计算目标市场总量。
3. 计算自己可交产能。
4. 反推所需顺位。
5. 根据市场大小、对手竞单详情、经验额估广告。
6. 比较广告额与产品利差。
7. 若广告消耗利差，考虑换市场、低广告获取订单或下一季再投。

广告投完后，必须根据实际广告排名重新预算。

广告不是成本项，而是市场控制工具。争一方案必须额外输出：

- 目标垄断市场：本年最值得抢的 1-2 个产品/市场/特性组合。
- 压制目标：希望把对手挤出哪些高毛利订单。
- 广告上限：广告超过多少会消耗产品利差。
- 广告下限：低于多少会丢掉关键顺位。
- 霸主判断：自己的可交产能是否足以覆盖目标订单，并让对手转向低毛利市场。

广告压制必须绑定产能，不允许“高广告低产能”：

```text
有效压制 = 高广告顺位 × 足够可交产能
无效压制 = 高广告抢到前排，但产能无法完全承接订单，剩余高毛利订单被对手承接
```

因此广告决策顺序必须是：

1. 先算本季度可交产能。
2. 再算目标市场/产品/特性的可承接订单量。
3. 判断自己能否覆盖前排订单或获取到足以压低对手收益的订单量。
4. 若产能不足，高广告只能买到选单权，不能形成垄断，应降低广告、补产能、换市场或拆分目标。
5. 若产能足够，高广告才有战略意义，因为它能把对手挤到低毛利或剩余订单。

高广告方案必须输出“广告覆盖率”：

```text
广告覆盖率 = 自己可交产能 / 目标高毛利订单池
```

- 覆盖率高：可以高广告压制并争市场霸主。
- 覆盖率低：高广告容易替对手筛掉订单，自己无法完全承接，别人承接剩余订单；应优先补线或降低广告。

## 10. 补线与拆线

补线不是“贷款够就补”，而是：

```text
有订单预期 + 有材料 + 有员工 + 有现金 + 产线投产时间赶得上
```

拆线公式：

```text
拆线净收益 =
(新线单季贡献 - 旧线单季贡献) × 剩余可生产季数
- 停产损失
- (新线价格 - 旧线残值)
```

拆线时点：

```text
投完广告 → 看到广告排名 → 交一交前贴现 → 根据可得订单反推极限线数 → 决定拆几条。
```

不是赛前固定拆，也不是订单完全确定后才想拆。

## 11. 四年运营框架

### Y1

- 打基础：市场、ISO、资质、关键材料。
- 用前期优势产品跑现金流。
- 不盲目保守。只要现金流能滚动支撑，应尽早建立产能优势和广告顺位优势。
- 年末必须覆盖税。

### Y2

- 根据 Y1 利润和贷款额度扩产。
- 高毛利产品出现时，补智能或拆自动。
- 广告开始按顺位抢关键订单。
- 目标是从“能接单”升级到“控制关键市场”，让对手被迫承接低毛利或剩余订单。

### Y3

- 产线接近上限。
- 主攻高毛利产品。
- 根据广告排名和订单预期动态拆线/转型。
- 若已形成产能优势，应集中火力垄断高毛利产品，不做平均主义排产。

### Y4

- 终局利润最大化。
- 贷款可更激进，但现金流不能断。
- 清库存、抢高价单、减少无收益投入。
- 终局广告和排产要围绕权益第一，不为保守现金余额牺牲高毛利订单。

## 12. 输出格式要求

任何正式方案必须输出：

- 题型分类。
- 产品毛利表。
- 市场大小和广告顺位表。
- 资质/市场/ISO完成表。
- 材料采购和付款表。
- 产线建设、投产、转产、拆线表。
- 每季度生产计划。
- 每季度现金流。
- 年末税款检查。
- 补线/拆线判断。
- 四年利润和期末权益。
- 风险点和可调项。
- 争一/市场霸主路径：说明本方案在哪一年、哪个产品、哪个市场形成领先，如何从领先变成垄断优势。

候选方案不得只给保守方案。至少输出：

- 产能激进方案：尽早上更多线，产量由现金控制。
- 现金保守方案：少线或低广告确保稳定。
- 混合转型方案：前期自动/低成本线跑现金，后期补智能或拆线。
- 低价规模化方案：前期用传统线或低价线建立订单承接能力，配合少量智能线准备高利润转型。

推荐方案必须说明为什么不是另外两个方案，而不是只给一个“能过”的答案。

候选方案对比必须至少包含：

- 第一年利润：用于判断 Y2 贷款额度和二年一季度广告资金。
- 第一年广告额：按广告时点现金口径计算，并说明可支撑的市场顺位。
- 达到最高有效产能时间：写清第几年第几季度，不只写“满线”。
- 注意事项：材料、资质、广告顺位、现金最低点、拆线/补线触发条件。

## 13. 不允许的错误

- 不读材料送货期就推荐线数。
- 不算广告顺位就写广告额。
- 不算税后现金就说年末安全。
- 不看转产周期就让自动线切高利润产品。
- 不看产线建成当季材料/紧采现金就提前建线。
- 不比较广告与产品利差就盲目追高利润产品。
- 不根据广告排名动态拆线，而赛前固定拆线。
- 把“满产现金流不过”误判为“不能多建线”。
- 用保守样例替代竞争性开局方案。
- 只算实际生产量，不先给极限产能和可抢订单上限。
- 忽略“早交/短账期/可贴现产品”对下一批高利润产品的现金托举作用。
- 因传统线生产周期长而直接排除低价大产能方案。
- 只看智能线后期灵活性，忽略传统线前期权益滚动和广告覆盖率优势。
- 不测算拆线重装，就默认传统线必须转产或必须保留。
