# 沙盘方案推演硬规则

这份规则来自用户对“我还不清楚哪些地方”的补充回答。它优先于通用模板、示例 Excel 和早期简化算法。后续任何方案推演、模型提示词、前端展示和后端计算，都必须以这里的口径为准；缺少证据时标注“不确定/需读取规则”，不能编造。

## 三个同等目标

1. 利润最大化：看四年总利润和期末所有者权益。
2. 产能最大化：尽早达到产线数量上限，并让产线尽可能满产高利润产品。
3. 现金流不断裂：每个季度末现金不能为负，交货前现金必须为正，且季度末现金应覆盖下一季刚性支出。

任何牺牲现金流导致破产、或盲目扩产导致长期亏损的方案都不合格。

## 订单链路

- 广告季：第一年 1.2、1.3；第二年 2.1、2.2；第三年 3.1、3.2；第四年 4.1、4.2。
- 生产周期 1 季：当季开产，下季初入库，可交对应交货批次。
- 生产周期 2 季：当季开产，再下一季入库。
- 建造周期 1 季：1.1 建，1.2 可开产。
- 建造周期 2 季：1.1 建，1.3 可开产。
- 建造周期 0 季：购买当季可开产，但必须有材料。
- Q1 入库是“1交”，Q2 入库是“2交”，Q3 入库是“3交”，Q4 入库是“4交”。
- 上一年 Q4 生产、下一年 Q1 入库的产品，属于下一年的“1交”。
- 回款季度 = 交货季度 + 账期。没有明确账期时，按 4 季账期做贴现压力测试。
- 贴现可提前回笼现金，贴息率按规则表读取。

## 材料采购

- 原料有送货周期，付款发生在到货当季。
- 排产前必须按产线产能倒推材料需求，提前按送货周期下采购单。
- 现金流中必须出现材料到货付款，不允许把材料成本只放到利润表里。

## 广告与市场

- 产能不能按平均分配口径计算，要按比赛竞争性抢单口径。
- 大市场：市场总需求能覆盖各队满产，广告可低。
- 中市场：部分队能冲高产，需要中等广告保证顺位。
- 小市场：只够少数队，必须高广告抢单，否则可能断流。
- 要拿特定订单时，用“订单数量 / 自己季产能”估算所需排名位次。
- 正常选单时，用“产品当季市场总量 / 2 / 自己产能”估算大致排名。
- 真实选单还要按规则里的竞单公式反推特性等级、价格和广告。

## 产线与排产

- 必须逐条产线排建造、投产、生产、入库、转产和拆线。
- 自动线：便宜、建造快，第一年可更快出货；若转产周期为 0，可作为前期利润和产能扩张核心。
- 智能线：贵、建造慢，但产能高、转产灵活；适合高利润产品来得早或自动线转产周期较长的规则。
- 传统线：不能凭空推荐；只有在规则证明其现金/产能组合更优时才考虑。
- 高级工激励通常优先拉到 100%，但激励必须发生在员工到岗、产线可开产时。
- 产能公式：基础产量 × (1 + 初级工效率和 / 4 + 高级工效率和) × 班次加成。
- 初级工激励要除以 4，必须比较“增产毛利”是否覆盖激励成本。

## 融资与贴现

- 第一、二年为了扩大产能，可积极使用贷款额度，但必须现金流安全。
- 第三年若产线已基本拉满，可减少贷款节省利息，但不能限制产能。
- 第四年因比赛结束，可拉出可用贷款做最后一年高利润覆盖。
- 通常优先短贷 + 贴现，少用长贷；长贷每季付息会持续压现金。
- 还款按当季手动操作：先交货/回款或贴现，再还到期贷款。
- 现金缺口在哪里出现，贷款或贴现就应该动态补在哪里，不应简单把贷款全部堆在 Q1 当作结论。

## 拆线判断

拆线必须计算净收益和现金安全，不允许凭感觉拆：

```text
净盈亏 = (新线单季毛利 - 旧线单季毛利) × 剩余季数
       - 停产损失
       - (新线价格 - 旧线残值)
```

净盈亏大于 0 且拆线后季度现金安全，才允许执行。拆线应分批，用前一批回款支撑下一批。

## 必须输出

- 四年总利润、期末所有者权益。
- 是否达到产线数量上限，达到时间，每条线平均利用率。
- 各季度末现金表，标出最低现金点和断流风险。
- 四年季度排产表：借款、还款、贴现、材料采购、生产、交货、回款。
- 三目标平衡结论：说明融资、广告、产线选择、转产/拆线如何共同保证利润、产能和现金流安全。
