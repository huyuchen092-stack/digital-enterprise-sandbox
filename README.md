# Digital Enterprise Sandbox

This project is a full-stack assistant for the 数智化企业模拟沙盘.

The backend is a Python FastAPI service for simulation data, document ingestion, AI-assisted analysis, and persistence. The frontend will provide the user interface for managing sandbox decisions, reviewing operating results, and interacting with the assistant.

The no-off-rule principle means the assistant should keep every recommendation tied to the active sandbox rules, constraints, and current simulation state instead of drifting into generic business advice.
